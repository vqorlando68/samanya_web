GUÍA DE ESTILOS Y PALETA DE COLORES - SAMANYA WELLNESS
================================================================================
Archivo de referencia de tokens de diseño, colores, contrastes y tipografía
para el desarrollo de la página web e interfaces digitales.

1. IDENTIDAD VISUAL Y TIPOGRAFÍA
--------------------------------------------------------------------------------
- Concepto: Salud, bienestar asistencial, calidez humana, confianza y accesibilidad.
- Tipografía de Títulos (Headings): 'Plus Jakarta Sans', sans-serif (pesos 600, 700, 800)
- Tipografía de Texto (Body):       'Work Sans', sans-serif (pesos 400, 500, 600)
- Google Fonts URL:
  https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@600;700;800&family=Work+Sans:wght@400;500;600;700&display=swap


2. PALETA PRINCIPAL (MODO CLARO / LIGHT MODE)
--------------------------------------------------------------------------------
Elemento                     HEX        RGB                  Uso principal
--------------------------------------------------------------------------------
Color Primario (Teal)        #068591    rgb(6, 133, 145)     Botones principales, enlaces, iconos destacados, brand
Color Acento (Ocre/Ámbar)    #C68A3D    rgb(198, 138, 61)    Llamados a la acción secundarios, destacados cálidos
Fondo de Página (Page Bg)    #F7F7F8    rgb(247, 247, 248)   Background general de la aplicación / web
Superficie / Card (Card Bg)  #FFFFFF    rgb(255, 255, 255)   Tarjetas de contenido, modales, contenedores
Superficie Neutra Alterna    #EFECE6    rgb(239, 236, 230)   Fondos secundarios, bloques de contenido suave
Fondo de Inputs / Campos     #F7F7F8    rgb(247, 247, 248)   Cajas de texto, selects, textareas
Texto Principal (Dark)       #292A24    rgb(41, 42, 36)      Títulos, encabezados y textos de alta legibilidad
Texto Secundario (Muted)     #5C6058    rgb(92, 96, 88)      Subtítulos, labels, metadatos, textos auxiliares
Borde / Divisor              #DEDBD1    rgb(222, 219, 209)   Líneas divisorias, bordes de tarjetas e inputs

6. CONFIGURACIÓN COMPATIBLE CON TAILWIND CSS
--------------------------------------------------------------------------------
Para configurar o extender en tailwind.config.js:

module.exports = {
  darkMode: 'class',
  theme: {
    extend: {
      colors: {
        primary: {
          DEFAULT: '#068591',
          light: '#14B8C7',
          dark: '#056e78',
        },
        accent: {
          DEFAULT: '#C68A3D',
          light: '#E5A853',
        },
        surface: {
          page: '#F7F7F8',
          card: '#FFFFFF',
          'dark-page': '#101413',
          'dark-card': '#181D1B',
        },
        status: {
          'success-bg': '#DFF3E7',
          'success-text': '#1E7A4C',
          'pending-bg': '#FBE9D2',
          'pending-text': '#9A5B12',
          'alert-bg': '#FBEAEA',
          'alert-text': '#8C2E2E',
          'info-bg': '#D9F0F1',
          'info-text': '#075158',
        }
      },
      fontFamily: {
        sans: ['"Work Sans"', 'sans-serif'],
        heading: ['"Plus Jakarta Sans"', 'sans-serif'],
      }
    }
  }
}
