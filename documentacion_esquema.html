01Propuesta Integral y Estándares de Arquitectura

El modelo de base de datos relacional para SAMANYA OS está normalizado en Tercera Forma Normal (3NF) y diseñado bajo las mejores prácticas de Oracle Database Enterprise:

1. Convención Foráneas ID_*

Toda clave foránea comienza obligatoriamente con ID_ (ej. ID_ROL, ID_USUARIO, ID_RESIDENTE, ID_ESTADO_CONSENTIMIENTO), garantizando consistencia semántica en todo el modelo.

2. Hora Oficial Bogotá (UTC-5)

Todos los campos de fecha toman por defecto la hora legal de Bogotá, Colombia mediante DEFAULT CAST(SYSTIMESTAMP AT TIME ZONE '-05:00' AS DATE), evitando desfases por la zona horaria del servidor físico.

3. Estándar de Auditoría Total

Todas las tablas contienen FECHA_CREACION DATE y ID_USUARIO_ULTIMA_MODIFICACION NUMBER(10), junto a secuencias dedicadas y triggers BEFORE INSERT.

pr_preparar_carga_archivo PROCEDURE Valida sede y residente, reserva SEQ_SMY_ARCHIVOS.NEXTVAL y genera el nombre almacenado hasheado y las rutas requeridas antes de iniciar la transferencia hacia Google Drive.

pr_copiar_archivo PROCEDURE Clona metadatos del archivo asignando un nuevo ID con su nuevo nombre hasheado, persistiendo vía DAO y ejecutando COMMIT.
pr_restaurar_archivo PROCEDURE Restaura el estado a ID_ESTADO_ARCHIVO = 1 vía DAO y ejecuta COMMIT.
fn_consultar_archivos_residente FUNCTION Retorna un SYS_REFCURSOR con el listado de documentos de un residente aplicando filtros de negocio.

05Especificación de Triggers y Secuencias en Oracle

Para garantizar la compatibilidad con todas las versiones de Oracle (11g a 23c), cada una de las 79 tablas cuenta con una secuencia y un trigger BEFORE INSERT asociado: 

-- Patrón estándar implementado para todas las tablas SMY_:
CREATE SEQUENCE SEQ_SMY_CONSENTIMIENTOS START WITH 1 INCREMENT BY 1 NOCACHE NOCYCLE;

CREATE OR REPLACE TRIGGER TRG_SMY_CONSENTIMIENTOS_BI
BEFORE INSERT ON SMY_CONSENTIMIENTOS
FOR EACH ROW
BEGIN
    IF :NEW.ID IS NULL THEN
        SELECT SEQ_SMY_CONSENTIMIENTOS.NEXTVAL INTO :NEW.ID FROM DUAL;
    END IF;
END;
/
